## Risk without sex

| Situation | Risk |
|---|---|
| Sharing needles or syringes | High |
| Needle-stick injury at work | Small; ask about PEP right away |
| Unlicensed tattoo or piercing | Possible if equipment is reused |
| Pregnancy, birth, breastfeeding | Preventable with care |
| Licensed tattoo shop | Very low |
| Shared razor | Very low for HIV; higher for hepatitis |
| Mosquito bite, toilet seat, dried blood | None |

Exposure in the last 72 hours? See [PEP](/hiv/pep/).

If you'd rather test privately, a [lab-processed home kit](/go/k1/) uses the same type of lab test as a clinic.
