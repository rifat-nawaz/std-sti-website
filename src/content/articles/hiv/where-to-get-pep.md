## Where to go

| Option | When |
|---|---|
| Emergency room | Any time, any day |
| Urgent care | During opening hours |
| Sexual health clinic | If you can be seen the same day |
| Pharmacy | In some states, pharmacists can start PEP |
| Telehealth | Can prescribe in some cases |

## What to bring

ID if you have it, insurance details, and the time of the exposure.

See [what PEP involves](/hiv/pep/).
