## What's usually included

| Infection | Typically included? |
|---|---|
| Chlamydia, gonorrhea | Yes |
| HIV | Yes |
| Syphilis | Yes |
| Trichomoniasis | Often |
| Hepatitis B and C | Often |
| Herpes | Sometimes (blood test) |
| HPV | No |
| *Mycoplasma genitalium* | No |
