## Which tests check for chlamydia?

| Test | Checks for chlamydia? |
|---|---|
| Pap smear (cervical cytology) | No |
| HPV test | No |
| Routine urinalysis or urine culture | No |
| Complete blood count | No |
| Drug test | No |
| Chlamydia NAAT (urine or swab) | Yes |

Prefer to test at home? A [lab-processed home test](/go/k1/) lets you collect a sample in private and get results online.

## How to make sure you're tested

Say: "Please test me for chlamydia and gonorrhea." Then check your results for a line such as "*Chlamydia trachomatis*, NAAT: not detected".

## The Pap sample exception

Some labs can run a chlamydia NAAT on the same liquid sample collected for a Pap test, but only if your clinician orders it.
