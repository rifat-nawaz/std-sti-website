## Compare

| | Syphilis | Herpes |
|---|---|---|
| Number | Usually one | Often several |
| Pain | Usually painless | Painful |
| Look | Firm, round, clean base | Blisters that break into shallow sores |
| Before it appears | Nothing | Tingling, itching |
| Comes back | No (new infection only) | Yes, outbreaks recur |
| Test | Blood test; swab of the sore | PCR swab of the sore |
