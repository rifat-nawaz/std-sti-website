## What a real report includes

| Item | Why it matters |
|---|---|
| Lab name and contact | Can be verified |
| Patient name or ID | Shows whose result it is |
| Collection date | Shows timing |
| Specimen type | Urine, throat, rectal, blood |
| Test names and results | Shows what was actually tested |

If you'd rather test privately, a [lab-processed home kit](/go/k1/) uses the same type of lab test as a clinic.

## Better ways to share

Show results in the official portal, or test together.
