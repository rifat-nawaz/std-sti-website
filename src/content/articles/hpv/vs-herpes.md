## Side by side

| | HPV | Herpes |
|---|---|---|
| Looks like | Soft bumps or warts | Blisters, then sores |
| Pain | Usually none | Often painful |
| Comes back | Warts can recur | Outbreaks recur |
| Cancer risk | Some types | No |
| Test | Exam; cervical screening | Swab of a sore |
| Vaccine | Yes | No |
