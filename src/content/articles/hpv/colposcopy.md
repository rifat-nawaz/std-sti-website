## Results

| Result | Meaning | Usual next step |
|---|---|---|
| Normal | No significant changes | Follow-up testing |
| CIN 1 | Mild changes | Monitoring |
| CIN 2 | Moderate changes | Often removal |
| CIN 3 | Severe changes | Removal |
